# Hugging Face

## What Is Hugging Face?

Hugging Face is a leading advocate for open source AI.

It fosters collaboration on:

* Models
* Datasets
* Applications

within the machine learning community.

Hugging Face is often referred to as the "GitHub of Machine Learning" because it promotes open source machine learning and AI.

---

## Why Hugging Face Matters

Training a state-of-the-art NLP (Natural Language Processing) transformer model requires significant financial investment.

This is often not feasible for startups and small businesses.

Hugging Face helps democratize AI development by providing access to pre-trained models through its platform.

These models can be used to develop proprietary AI systems without incurring the massive costs associated with training an LLM from scratch.

---

## Transformers Library

Hugging Face introduced the Transformers Python library.

The library helps AI developers:

* Access pre-trained models
* Use models through APIs
* Create machine learning pipelines

The Transformers library provides an efficient way to work with modern machine learning models.

---

## What Can You Do with Hugging Face?

Users can:

* Share machine learning models
* Use pre-trained models
* Fine-tune machine learning models
* Host demos
* Evaluate machine learning models

---

## Company Background

Founded in 2016, Hugging Face has achieved a valuation exceeding $4.5 billion.

This indicates significant resources and commercial success.

---

## Open Source and Infrastructure

Like GitHub, which is owned by Microsoft, Hugging Face's infrastructure is not open source.

However:

* User-uploaded models are open source.
* User-uploaded datasets are open source.
