# Fundamentals — Summary

## What This Section Covers

This section connects programming, Python, data, machine learning, language
models, and the LLM development lifecycle.

## File Guide

- `Programming.md` — Problem decomposition and readable instructions.
- `WhyPython.md` — Python's accessibility, ecosystem, and broad use cases.
- `PythonProgramming.md` — Python tools used in AI applications.
- `DataFundamentals.md` — Data forms, quality, labels, and metadata.
- `MLAndDeepLearning.md` — Learning types, neural networks, and deep learning.
- `MLFundamentals.md` — Why self-supervision enables LLM-scale training.
- `LanguageModels.md` — N-grams, RNNs, LSTMs, and Transformers.
- `PhasesInBuildingLLMs.md` — Design through final evaluation.
- `README.md` — Recommended study order and high-level concept map.

## Core Learning Path

```text
programming -> Python -> data -> machine learning
            -> language models -> LLM lifecycle
```

## Key Takeaway

AI development builds upward from clear programming logic and good data.
Sophisticated model architectures cannot compensate for unclear requirements,
poor-quality data, or weak evaluation.
