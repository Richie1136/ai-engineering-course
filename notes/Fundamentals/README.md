# Fundamentals — Study Guide

These notes introduce the concepts needed before moving into the more detailed
NLP and large-language-model sections.

## Suggested Learning Order

1. [Programming](Programming.md) — Problem solving, mechanistic thinking, and
   readable code.
2. [Why Python?](WhyPython.md) — Why Python is widely used across data and AI.
3. [Python Programming for AI](PythonProgramming.md) — How Python libraries and
   APIs support AI application development.
4. [Data Fundamentals](DataFundamentals.md) — Data types, representation,
   collection, labeling, metadata, and quality.
5. [Machine Learning and Deep Learning](MLAndDeepLearning.md) — The relationship
   between AI, machine learning, deep learning, and neural networks.
6. [Efficiency of LLM Training](MLFundamentals.md) — Supervised, unsupervised,
   and self-supervised learning.
7. [Language Models](LanguageModels.md) — The progression from n-grams through
   recurrent networks to Transformers.
8. [Phases of Building LLMs](PhasesInBuildingLLMs.md) — The complete lifecycle
   from model design and data engineering to evaluation and release.

## Big Picture

```text
programming skills
        ↓
Python tools and libraries
        ↓
high-quality data
        ↓
machine-learning methods
        ↓
language-model architectures
        ↓
LLM training and evaluation lifecycle
```

Each lesson begins with a key takeaway and ends with a compact review section
or comparison table for quick reference.
