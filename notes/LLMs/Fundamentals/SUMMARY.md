# LLM Fundamentals — Summary

## File Guide

- `LLMFundamentals.md` — Introduces large language models, their training,
  capabilities, terminology, and common uses.

## Key Takeaways

- LLMs learn statistical patterns over tokens from large text collections.
- A model generates output by repeatedly predicting likely next tokens.
- Scale refers to training data, parameter count, and computational resources.
- General language ability does not guarantee factual accuracy or access to
  private and current information.
- Prompts provide instructions and context at inference time; they do not
  retrain the model.

## Review Checklist

- Can you distinguish a token, parameter, prompt, context window, and response?
- Can you explain why fluent output may still be incorrect?
- Can you identify when external data or evaluation is required?
