# OpenAI Models and Pricing

## Overview

OpenAI's large language models are priced based on **token usage**.

The more input text you provide and the more output text the model generates, the more tokens are consumed and the higher the cost.

The total cost depends on both:

- The number of tokens used
- The model being used

---

## GPT-4

Throughout this course, we'll primarily be using **GPT-4**.

Some of its key characteristics include:

- Most efficient model
- Most affordable model
- Most advanced model

---

## Input and Output Token Pricing

OpenAI prices **input tokens** and **output tokens** separately.

### Input Tokens

Input tokens are the tokens you send to the model as part of your prompt.

At the time this course was created:

- **$5 per million input tokens**

Although one million tokens sounds large, it is roughly equivalent to a **1,500-page novel**, making the cost relatively low for many applications.

---

### Output Tokens

Output tokens are the tokens generated by the language model in its response.

At the time this course was created:

- **$15 per million output tokens**

Output tokens are more expensive because generating responses requires additional computation.

Some pricing pages also display these costs **per 1,000 tokens** instead of per million tokens.

---

## Context Window

Every language model has a **context window**, which determines the maximum number of tokens that can be processed in a single request.

The context window includes both:

- Input tokens
- Output tokens

This means that very large documents cannot be passed to the model all at once.

For example, you couldn't submit an entire novel such as *The Lord of the Rings* in a single prompt, nor should you expect the model to generate an output of that size.

---

## GPT-4o Context Window

For GPT-4o, the maximum context window is:

- **128K tokens**

This limit is shared between both the prompt and the generated response.

For example, using a larger prompt leaves fewer tokens available for the model's output.

---

## Choosing the Right Model

When selecting an OpenAI model for your application, there are several important factors to consider:

- Price per input token
- Price per output token
- Training data cutoff date
- Maximum context window

The best model depends on your application's requirements, budget, and the amount of context needed.
