# Introduction to Natural Language Processing (NLP)


Natural Language Processing (NLP) is a field of Artificial Intelligence (AI) that enables computers to understand, interpret and generate human language data.

## Core Techniques

 - Statistics
 - Machine Learning
 - Deep Learning

 NLP came to life around the 1950s, but early methods focused on rule-based systems, taking grammatical rules of the language and using this to try and process the text. However trying to just learn simple grammatical rules isn't enough to be able to speak and have a conversation that you truly understand that language. More recently, we've had massive advancements in technology and the availability of large data sets
for training our NLP models. This has led to things like ChatGPT that can really effectively understand and communicate with human like language. For data scientists, NLP provides such a powerful set of tools for gaining insights from text data.
By leveraging NLP techniques, you'll be able to save massive amounts of time and uncover insights that previously might not have been uncovered.

## NLP in everyday life

One key example is search engines that will use NLP to understand a user's query and provide relevant search results.

NLP techniques are used to extract keywords, understand the intent of the user's query, and return relevant and matching web pages.

Another great example is how your email account can automatically detect spam emails.

Classification algorithms can be used to find patterns that differentiate between unwanted and legitimate emails.

Customer support systems and chatbots also use NLP to understand customer queries.

Data scientists can build conversational agents that can understand what the customer is asking for, and provide relevant responses back.


## Common NLP Applications

 - Search engines
 - Machine translation
 - Chatbots
 - Virtual assistants (Siri, Alexa)
 - Spam detection
 - Sentiment analysis
 - Text summarization
 - Question answering (ChatGPT)


## Supervised vs Unsupervised Machine Learning Solutions for NLP

### Supervised Learning

Supervised learning involves training an algorithm to learn the relationship between the input, which would be our text data, and an output that
we also provide.

**Example**

You have a dataset of reviews, you have the review text, and then each reviewer also gives a review score out of ten. You can feed this into a supervised
machine learning algorithm that will learn the relationship between the input text and the score to be able to make predictions about the score on new text data.

### Unsupervised Learning

Unsupervised learning doesn't need labels. It can find patterns in the data without it.

**Example**

If you've ever done any clustering before or you've heard of clustering, this is a great example of an unsupervised machine learning technique.

Unsupervised learning is great when you have unlabeled data, but still want to be able to identify patterns or group similar items together.


## Summary

Supervised Learning: Uses labeled data to make predictions.

Unsupervised Learning: Finds hidden patterns in unlabeled data.


## Key Takeaways

 - NLP allows computers to understand and generate human language.
 - Modern NLP relies heavily on machine learning and deep learning.
 - Supervised learning requires labeled data.
 - Unsupervised learning discovers patterns without labels.
 - NLP powers many everyday applications such as search engines,
   spam filters, chatbots, and recommendation systems.
