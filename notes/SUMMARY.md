# AI Engineer Course Notes — Master Summary

This page is the starting point for the course notes. Each linked section has
its own `SUMMARY.md` with a file guide, core ideas, and review material.

- [AI Engineering Overview](AIEngineeringOverview.md) — Distinguishes AI,
  machine learning, data science, narrow AI, and AGI.

## Foundations

- [Fundamentals](Fundamentals/SUMMARY.md) — Programming, Python, data, machine
  learning, language-model evolution, and the LLM lifecycle.
- [AI Branches](AI_Branches/SUMMARY.md) — Computer vision, NLP, robotics, and
  generative AI.

## Building AI Systems

- [AI Engineering](AI_Engineering/SUMMARY.md) — APIs, frameworks, retrieval,
  evaluation, optimization, and cost.
- [Large Language Models](LLMs/SUMMARY.md) — Transformer architecture, GPT,
  BERT, XLNet, Hugging Face, and LangChain.
- [LLM Challenges](LLM_Challenges/SUMMARY.md) — Inconsistency, latency, and
  training-data constraints.
- [Natural Language Processing](NLP/SUMMARY.md) — Text preparation,
  representation, analysis, classification, and future directions.
- `PandasLibrary.md` — Quick notes about tabular data manipulation with pandas.

## Careers and Responsibility

- [AI Careers](Careers/SUMMARY.md) — Engineer, developer, and strategist roles.
- [Looking Ahead](Looking_Ahead/SUMMARY.md) — AI ethics and future impact.

## Suggested Course Path

```text
Fundamentals -> AI Branches -> NLP and LLMs -> AI Engineering
             -> LLM Challenges -> Careers and Ethics
```

The order is flexible: use the nearest `SUMMARY.md` as a reference whenever a
lesson introduces unfamiliar terminology or you need to revisit the big picture.
